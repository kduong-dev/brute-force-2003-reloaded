# Project instructions

The full instructions for this repository are in [CLAUDE.md](CLAUDE.md). Read it before
starting work; it covers the layout, build, verification, team workflow and conventions.

`Brute Force/`, `Brute Force DLC/`, `decompiled/` and `todo/` hold the original game's files,
data extracted from them and reference captures. They are git-ignored: never commit them, and
never copy game data into the repository.
